# НВБНН — подписанный реестр лицензий

Этот репозиторий содержит публичный файл проверки лицензий НВБНН.
Приложение скачивает `licenses.json` без авторизации и проверяет подпись Ed25519
встроенным публичным ключом. Лицензионные ключи и ID установок клиент не отправляет.

В подписанных данных публикуются только:

- отпечаток случайного лицензионного ключа;
- хэш ID установки;
- срок действия и статус лицензии;
- номер снимка, время его создания и срок действия.

Полных ключей, названий заказчиков, исходных ID установок, исходников приложения
и закрытого ключа подписи в репозитории нет. Изменение файла без подписи издателя
не даёт действующую лицензию. Публичная история сохраняет предыдущие снимки;
клиент проверяет срок и номер снимка, а не только подпись.

Снимок обновляется автоматически каждый час и после изменения лицензий.
Он действует не более 24 часов с момента создания. Задержки GitHub Actions/CDN
возможны; отсутствие нового снимка не продлевает старый.

Выдача, продление и перенос лицензии выполняются через поставщика НВБНН.
Этот репозиторий не является API активации и не принимает ключи пользователей.
